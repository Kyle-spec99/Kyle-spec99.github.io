# Bouncing Ball Animation – Math-Based Animation

## Project Description

This project is a simple Math-Based Animation created using **p5.js** and JavaScript.

The Bouncing Ball Animation shows a ball moving diagonally across the screen and bouncing whenever it reaches the edges of the canvas.

It uses mathematical calculations, variables, and conditions to control the ball's position, speed, and direction.

## Keyboard Controls

| Key | Function |
|---|---|
| SPACE | Pause / Resume the animation |
| + | Increase the ball's speed |
| - | Decrease the ball's speed |
